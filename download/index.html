Helper

Download the latest Windows helper installer from GitHub Releases:

  • (Recommended)Windows helper installer, self-contained
  • Windows helper installer, framework-dependent

Most users should download the self-contained installer. It includes the required runtime dependencies. If you strongly care about installer size and already have the required .NET and WinUI runtime dependencies installed, you can use the framework-dependent installer instead.

Plugin

Download the latest Stream Deck plugin package from GitHub Releases:

  • ShoMetrics Stream Deck plugin
  • SHA256 checksums

The Stream Deck plugin package can also be submitted manually to Elgato Marketplace when preparing a Marketplace release.

These links use GitHub’s latest full release. Prerelease builds may be available from the GitHub Releases page before they appear here.

Product-only releases may appear on GitHub before the next full release. The links above intentionally continue to point at the latest full release so each download link has a matching file.
